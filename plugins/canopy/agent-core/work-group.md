# Work group — renamed: see `checkin.md`

Work groups became **project check-ins** (canopy-web spec 2026-10-17-project-check-ins-design.md):
the project is the unit, and a check-in is how it meets. Follow agent-core `checkin.md` (one
agent) or `huddle.md` § Check-in runs (several). `--group-run` and `canopy huddle-group …` still
work as aliases of `--checkin-run` and `canopy checkin …` for one release.
