# Huddle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A team of agents (leader + members) runs a typed, multi-round huddle; canopy-web shows the
conversation and its live outputs at `/w/<ws>/huddles/<id>`; the first type is `work` and the first
team is Ada's fleet.

**Architecture:** canopy-web gets a DERIVED huddle API (no new models): it reads turns tagged
`origin_ref.huddle`, members' close-out reports whose ```huddle block names the huddle, and tasks
whose `source_url` is the huddle page. The canopy CLI (`canopy huddle …`) is stateless between steps:
it dispatches tagged round turns, reads progress back from that API, applies the type's gates, files
outcomes as board tasks, and writes a clean-outcomes JSON record to the leader's Drive
`Process State/Huddles/`. Ada binds it with a thin skill.

**Tech Stack:** canopy-web — Django + Ninja (pytest), React 19 + TS + Tailwind 4 + openapi-fetch
(vitest). canopy — Python 3.11 + Click (pytest), gog CLI for Drive. ada — skills (markdown).

**Spec:** `docs/superpowers/specs/2026-10-06-huddle-design.md` (canopy repo).

## Global Constraints

- Huddle id format: `<type>-<team>-<YYYYMMDD>` (UTC date), suffix `-2`, `-3`… when taken.
- Round turns: `origin_ref = {"kind": "huddle_round", "huddle": H, "type": T, "round": N, "member": M, "attempt": K, "thread_key": "<idempotency key>"}`, `parent = {"turn": <anchor turn id>}`, idempotency key `huddle-<H>-<M>-r<N>-a<K>`, never `runner_id`.
- Anchor (leader) turn: close-out `POST /api/agents/<leader>/turns/` with `cli_session_id = "huddle:<H>"`, `origin_ref = {"kind": "huddle", "huddle": H, "type": T, "team": TEAM, "leader": L, "members": [...]}`.
- Reply block: a fenced ```` ```huddle ```` JSON block whose top level has `"huddle": H, "round": N, "member": M`. The member puts it in its final message AND files it as its close-out (`canopy agent turn --slug M --title "huddle H round N" --summary "<block>"`).
- Round deadline: 90 minutes after the earliest round-1 turn's `created_at` (derived, never stored).
- Max 3 rounds; ≤3 proposals per member per round; ≤5 filed outcomes per huddle.
- Outcome tasks: `status="suggested"`, `source_url = <huddle page URL>`, owner = principal name.
- Drive record path: `<GDRIVE_ROOT_FOLDER>/Process State/Huddles/<H>.json` (single writer: the leader).
- canopy CLI in skills is invoked as `uv run --project "$CANOPY_ROOT" canopy …` (enforced by `tests/test_plugin_runtime_resolution.py`).
- canopy-web: every `schemas.py`/`api.py` change regenerates and commits `frontend/src/api/generated.ts`; every new route gets a `frontend/src/guide/surfaces.ts` descriptor; PRs merge via `gh pr merge <n> --auto` (no strategy flag).
- canopy: bump with `uv run canopy version bump` when `plugins/canopy/` changes; new modules must be tiered in `tests/test_plugin_boundary.py` and `src/orchestrator/TIERS.md`.

## Review Focus

- A member's close-out never reached canopy-web (cloud runner streamed nothing) → the API falls back to the round turn's retained transcript; if neither exists the cell says "no reply yet" (pending) or "no reply" (turn finished) — never a 500.
- A member replies with a malformed or wrong-huddle block (copied a previous huddle's id, or wrong round) → it is ignored for this cell; `reply_error` explains; the CLI re-prompts on the next round.
- A viewer who may see THAT a turn ran but not its content (`content_hidden`) opens a huddle page → cells show status only, no prompt/reply text leaks through the huddle API.
- Re-running `canopy huddle file` after a partial failure → tasks are found by (agent, source_url, title) and not duplicated; the Drive record is replaced, not appended.
- Two huddles of the same type/team on the same day → the second gets `-2` and its turns never mix with the first's (tags + block huddle id both checked).

`apps/huddles/services.py`:
```python
"""Huddles are DERIVED, never stored (canopy docs/superpowers/specs/2026-10-06-huddle-design.md).

A huddle is: one anchor turn (`origin_ref.kind == "huddle"`, a report-only row the leader
files), the round turns tagged `origin_ref.huddle`, each member's reply (a ```huddle block it
files as its close-out, else found in the round turn's retained transcript), and the board
tasks whose `source_url` is the huddle page. All reads go through the caller's visible-turn
queryset so a huddle can never show what `/api/harness/turns/` would not."""
from __future__ import annotations

import datetime as dt
import json
import re

from apps.agents.models import AgentTask
from apps.harness import services as hsvc
from apps.harness import turn_access
from apps.harness.models import Turn

_FENCE = re.compile(r"```huddle\s*\n(.*?)\n```", re.S)
DEADLINE = dt.timedelta(minutes=90)


def extract_block(text: str, huddle: str, round_no: int) -> tuple[dict | None, str]:
    """The LAST ```huddle block in `text` that names this huddle + round. ('' error = ok)."""
    err = ""
    for raw in reversed(_FENCE.findall(text or "")):
        try:
            b = json.loads(raw)
        except ValueError as e:
            err = f"reply block is not valid JSON: {e}"
            continue
        if not isinstance(b, dict):
            err = "reply block is not a JSON object"
            continue
        if str(b.get("huddle")) == huddle and int(b.get("round") or 0) == round_no:
            return b, ""
        err = err or f"block names huddle {b.get('huddle')!r} round {b.get('round')!r}"
    return None, err


def anchors(visible_qs):
    return visible_qs.filter(origin_ref__kind="huddle")


def _closeout_texts(visible_qs, member: str, huddle: str, since):
    rows = (visible_qs.filter(agent__slug=member, report_summary__contains=huddle,
                              created_at__gte=since)
            .order_by("-created_at").values_list("report_summary", flat=True))
    return list(rows)


def _transcript_text(turn) -> str:
    try:
        msgs, _ = hsvc.transcript_messages(turn)
    except Exception:  # a broken blob must not 500 the page
        return ""
    return "\n".join(m.get("plaintext") or "" for m in msgs if m.get("role") == "assistant")


def cell(turn, *, huddle, user, visible_qs, since, memo) -> dict:
    ref = turn.origin_ref or {}
    member, rnd = str(ref.get("member") or ""), int(ref.get("round") or 0)
    readable = turn_access.can_read_turn_content(user, turn, memo)
    out = {"member": member, "round": rnd, "attempt": int(ref.get("attempt") or 1),
           "turn_id": str(turn.id), "status": turn.status, "created_at": turn.created_at,
           "finished_at": turn.finished_at, "content_hidden": not readable,
           "prompt": turn.prompt if readable else "", "block": None,
           "reply_source": "none", "reply_error": "",
           "has_transcript": hasattr(turn, "transcript")}
    if not readable:
        return out
    if turn.report_summary:
        b, err = extract_block(turn.report_summary, huddle, rnd)
        if b:
            return {**out, "block": b, "reply_source": "closeout"}
        out["reply_error"] = err
    for text in _closeout_texts(visible_qs, member, huddle, since):
        b, err = extract_block(text, huddle, rnd)
        if b and str(b.get("member") or member) == member:
            return {**out, "block": b, "reply_source": "closeout", "reply_error": ""}
        out["reply_error"] = out["reply_error"] or err
    b, err = extract_block(_transcript_text(turn), huddle, rnd)
    if b:
        return {**out, "block": b, "reply_source": "transcript", "reply_error": ""}
    out["reply_error"] = out["reply_error"] or err
    return out


def summary(anchor, visible_qs) -> dict:
    ref = anchor.origin_ref or {}
    hid = ref.get("huddle", "")
    rounds = visible_qs.filter(origin_ref__huddle=hid, origin_ref__kind="huddle_round")
    return {"id": hid, "type": ref.get("type", ""), "team": ref.get("team", ""),
            "leader": ref.get("leader") or anchor.agent.slug,
            "members": list(ref.get("members") or []), "anchor_turn_id": str(anchor.id),
            "created_at": anchor.created_at, "finished": bool(ref.get("finished_at")),
            "outcome_count": outputs_qs(hid).count(),
            "rounds_dispatched": max([int((t.origin_ref or {}).get("round") or 0)
                                      for t in rounds] or [0])}


def outputs_qs(huddle: str):
    # The page URL ends with /huddles/<id>; match the exact tail so h1 never matches h10.
    return (AgentTask.objects.select_related("agent")
            .filter(source_url__regex=rf"/huddles/{re.escape(huddle)}/?$"))


def detail(anchor, *, user, visible_qs) -> dict:
    base = summary(anchor, visible_qs)
    hid = base["id"]
    rounds = list(visible_qs.filter(origin_ref__huddle=hid, origin_ref__kind="huddle_round")
                  .order_by("created_at"))
    latest: dict[tuple[str, int], Turn] = {}
    for t in rounds:
        ref = t.origin_ref or {}
        k = (str(ref.get("member") or ""), int(ref.get("round") or 0))
        if k not in latest or int(ref.get("attempt") or 1) >= int(
                (latest[k].origin_ref or {}).get("attempt") or 1):
            latest[k] = t
    memo: dict = {}
    since = anchor.created_at - dt.timedelta(minutes=5)
    cells = [cell(t, huddle=hid, user=user, visible_qs=visible_qs, since=since, memo=memo)
             for t in latest.values()]
    r1 = [t.created_at for (_, r), t in latest.items() if r == 1]
    ws = anchor.agent.workspace_id
    outputs = [{"agent": a.agent.slug, "task_id": a.id, "ext_id": a.ext_id, "title": a.title,
                "status": a.status, "assigned": a.assigned,
                "project": getattr(a.project, "ext_id", "") if getattr(a, "project_id", None) else "",
                "url": f"/w/{a.agent.workspace_id or ws}/agents/{a.agent.slug}/work"}
               for a in outputs_qs(hid).filter(agent__workspace_id=ws)]
    return {**base, "summary": anchor.report_summary,
            "deadline_at": (min(r1) + DEADLINE) if r1 else None,
            "cells": cells, "outputs": outputs}
```

from django.http import HttpRequest
from ninja import Router
from ninja.errors import HttpError

from apps.harness.api import visible_turns_qs
from . import services
from .schemas import HuddleOut, HuddleSummaryOut

router = Router(tags=["huddles"])


@router.get("/", response=list[HuddleSummaryOut], summary="List huddles (derived from anchor turns)",
            openapi_extra={"x-mcp-expose": True})
def list_huddles(request: HttpRequest, agent: str | None = None, limit: int = 50):
    """Huddles the caller can see, newest first. `agent` keeps those it led or joined."""
    vis = visible_turns_qs(request)
    out = []
    for a in services.anchors(vis)[: max(1, min(limit, 200)) * 3]:
        s = services.summary(a, vis)
        if agent and agent != s["leader"] and agent not in s["members"]:
            continue
        out.append(s)
        if len(out) >= limit:
            break
    return out


@router.get("/{huddle_id}", response=HuddleOut, summary="One huddle: its conversation and outputs",
            openapi_extra={"x-mcp-expose": True})
def get_huddle(request: HttpRequest, huddle_id: str):
    """Rounds × members, each cell the member's reply block (from its close-out, else its
    transcript), plus the board tasks the huddle produced with their live status."""
    vis = visible_turns_qs(request)

```python
"""Huddle — a team of agents syncs, led by one of them. The PURE half: ids, keys, tags,
huddle-type loading/rendering/validation, and the `work` type's gates. No I/O here —
huddle_cli.py talks to canopy-web and huddle_store.py to Drive.
Spec: docs/superpowers/specs/2026-10-06-huddle-design.md."""
from __future__ import annotations

import dataclasses
import datetime as dt
import json
import re
from importlib.resources import files

MAX_ROUNDS = 3
MAX_OUTCOMES = 5
_VAR = re.compile(r"\{\{(\w+)\}\}")


def huddle_id(type_, team, day, taken):
    base = f"{type_}-{team}-{day:%Y%m%d}"
    if base not in taken:
        return base
    n = 2
    while f"{base}-{n}" in taken:
        n += 1
    return f"{base}-{n}"


def idempotency_key(huddle, member, round_no, attempt):
    return f"huddle-{huddle}-{member}-r{round_no}-a{attempt}"


def round_origin_ref(huddle, type_, round_no, member, attempt):
    return {"kind": "huddle_round", "huddle": huddle, "type": type_, "round": round_no,
            "member": member, "attempt": attempt,
            "thread_key": idempotency_key(huddle, member, round_no, attempt)}


def anchor_origin_ref(huddle, type_, team, leader, members):
    return {"kind": "huddle", "huddle": huddle, "type": type_, "team": team,
            "leader": leader, "members": list(members)}


@dataclasses.dataclass(frozen=True)
class HuddleType:
    name: str
    rounds: dict
    schema: dict


def load_type(type_):
    root = files("orchestrator.huddle_types").joinpath(type_)
    schema = json.loads(root.joinpath("schema.json").read_text(encoding="utf-8"))
    rounds = {}
    for n in range(1, MAX_ROUNDS + 1):
        f = root.joinpath(f"round{n}.md")
        if f.is_file():
            rounds[n] = f.read_text(encoding="utf-8")
    if not rounds:
        raise ValueError(f"huddle type {type_!r} has no round templates")
    return HuddleType(type_, rounds, schema)


def render_round(ht, round_no, ctx):
    tmpl = ht.rounds[round_no]
    missing = sorted({m for m in _VAR.findall(tmpl) if m not in ctx})
    if missing:
        raise ValueError(f"round {round_no} template needs: {', '.join(missing)}")
    return _VAR.sub(lambda m: str(ctx[m.group(1)]), tmpl)


def validate_block(ht, round_no, block):
    spec = ht.schema["rounds"][str(round_no)]
    probs = []
    if not isinstance(block, dict):
        return ["block is not a JSON object"]
    for key in ("huddle", "round", "member"):
        if key not in block:
            probs.append(f"missing {key}")
    for key, rule in spec["fields"].items():
        if key not in block:
            if rule.get("required"):
                probs.append(f"missing {key}")
            continue
        v = block[key]
        if rule["type"] == "list":
            if not isinstance(v, list):
                probs.append(f"{key} must be a list")
            elif "max" in rule and len(v) > rule["max"]:
                probs.append(f"{key} has {len(v)} items (max {rule['max']})")
            elif rule.get("item_fields"):
                for i, item in enumerate(v):
                    for f in rule["item_fields"]:
                        if not isinstance(item, dict) or f not in item:
                            probs.append(f"{key}[{i}] missing {f}")
        elif rule["type"] == "str" and not isinstance(v, str):
            probs.append(f"{key} must be a string")
    return probs


def _norm(s):
    return re.sub(r"\W+", " ", str(s).lower()).strip()


def work_gates(proposals, r1_priorities, prior_declined):
    pri = {_norm(p) for p in r1_priorities}
    declined = {_norm(d["title"]): d for d in prior_declined
                if str(d.get("fate", "")).startswith("declined")}
    filed, held = [], []
    for p in proposals:
        partners = [m for m in p.get("with") or [] if m != p.get("lead")]
        ans = p.get("answers") or {}
        reason = ""
        bad = [m for m in partners if ans.get(m) == "decline"]
        missing = [m for m in partners if ans.get(m) != "co-sign"]
        if bad:
            reason = f"{bad[0]} declined"
        elif missing:
            reason = f"{missing[0]} has not co-signed"
        elif not any(_norm(p.get("priority")) == x or _norm(p.get("priority")) in x for x in pri):
            reason = f"priority not stated in any round-1 report: {p.get('priority')!r}"
        elif not p.get("critique_answered"):
            reason = "critique not answered"
        elif _norm(p["title"]) in declined and not p.get("new_evidence"):
            reason = f"declined before ({declined[_norm(p['title'])]['fate']}) and no new evidence"
        elif len(filed) >= MAX_OUTCOMES:
            reason = f"over the {MAX_OUTCOMES}-outcome cap"
        if reason:
            held.append({**p, "held": reason})
        else:
            filed.append(p)
    return filed, held


def outcome_record(meta, filed, held, not_reached):
    def row(p, fate):
        return {k: p.get(k) for k in ("title", "lead", "with", "priority", "project", "task",
                                      "answers", "why")} | {"fate": fate}
    return {"version": 1, **{k: meta.get(k) for k in ("id", "type", "team", "leader", "members",
                                                      "leader_turn", "started_at")},
            "finished_at": dt.datetime.now(dt.timezone.utc).isoformat(timespec="seconds"),
            "outcomes": [row(p, "filed") for p in filed] + [row(p, f"held: {p['held']}") for p in held],
            "not_reached": list(not_reached)}
